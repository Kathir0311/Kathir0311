    Our own AI

    Meet DezAI — the AI that lives on your server.

    Dez AI is the studio’s own AI: a self-learning brain that works offline and is trained on your approved files — and taught by the Online AI, a language and vision model on your own network. It proposes every tag, drafts every alt text, explains its choice and learns from every correction — and nothing you give it ever leaves your network.

    • Tags a whole file in one pass

      Headings, paragraphs, lists, tables, figures, captions, links, footnotes, contents and reading order — proposed together.

    • Writes the alt text

      A draft description for every picture from the Online AI’s vision model; decorative ones become artifacts; a picture described once is remembered.

    • Learns from your corrections — live

      Change a tag or cut a zone once. A few seconds later Dez AI offers the same fix everywhere in the file and uses it on the next files of that client.

    • Learns from the Online AI, its teacher

      Every answer the Online AI gives is kept as a lesson. Next time Dez AI answers the same kind of question itself — in a blink, even offline — and checks itself against the Online AI now and then.

    • Knows each client’s style

      Learns the house rules from approved files — what is a heading, where a paragraph ends — and keeps one convention inside a file.

    • Shows its reasons

      Every proposal says how sure it is and why; the doubtful tags are listed first, so your time goes where it matters.

    • Private by design

    • Document is tagged and marked as tagged
    • Language and title are set, and the title is shown
    • The structure tree is whole and well formed
    • Reading order follows the page
    • Heading levels never skip
    • Every figure has alt text — or is an artifact
    • Tables have header cells and scope
    • Lists are lists, with their items and labels
    • Links have a destination and a description
    • Form fields have labels
    • Fonts are embedded and text maps to Unicode
    • Text contrast is measured on the real background
    • Bookmarks follow the headings
    • The metadata declares PDF/UA-1

    Questions

    What clients ask before they start.

    Straight answers — including the limits.

    Is the result certified PDF/UA?

    No tool can certify that by itself. The studio checks every build against ISO 14289-1 and WCAG 2.1 AA with {{ facts.checks }} machine checks, runs veraPDF when you install it, and lists what only a person can judge — the quality of an alt text, whether a reading order makes sense — in a manual checklist. Confirm delivery files in PAC 2024 and veraPDF; the workflow asks for the PAC report before a file goes to QA.

    Do my files leave my server?

    No. The studio, Dez AI, the Online AI that teaches it and the learning database all run on your own network. Every connection outside it is refused before a byte is sent, and logged — if the Online AI should live elsewhere, your admin has to name that host in the Privacy guard first. The pages load no font, script or picture from the internet.

    What do we need to run it — and is a GPU required?

    A Linux or Windows server with Python 3.10 or newer, and a browser for everybody else. Tesseract (for scanned pages), veraPDF and the Online AI (a language and vision model server on your network) are optional. Tagging, checking and editing need no GPU; the Online AI’s models run faster on one but work on a CPU too — and DezAI needs them less as it learns. Without the Online AI the studio still works.

    Can the AI learn something wrong?

    Learning has to prove itself first: a model or a rule acts only after it was right on files it was not trained on, a learned rule that people keep undoing is retired by itself, and what your team decides in a file counts more than any AI answer. An admin can switch each part off.

    Can many people work at the same time?

    Yes. The queue serves each person in turn and runs several files at once; in a file one person edits while the others watch, so nobody’s work is overwritten. An admin sees who works on what, and for how long.

    Which PDFs does it handle?

    Journal articles, books, reports exported from Word or InDesign, forms, worksheets, and files that already have tags — which can be imported as they are. Scanned pages get a text layer when Tesseract is installed.

    Which languages?

    Any text in Unicode — Tamil, Greek, accented Latin and more — is read and tagged, with the language set for each passage so assistive technology can switch voice. The languages OCR can read depend on the Tesseract language packs you install.

    Can we follow a client’s house style?

    Yes. A profile holds a client’s options, the client’s approved PDFs teach DezAI their conventions, and a client can have a tag structure of its own.

    Can it run in batches or from scripts?

    Yes: upload files in the browser (an admin can upload a whole folder), or use the command line — with a profile, options, a check-only mode that returns an error code, and a batch summary workbook.
